OTP-R1 through OTP-R5 implementation is complete. OTP-R6 is ready but requires your Google App Password and manual receipt confirmation, which I cannot safely perform for you.
No migration, database object, transaction-state logic, JWT logic, or unrelated module was altered.
What was implemented
- Added explicit routing modes:
  - FIXED_OVERRIDE for the showcase.
  - STORED_USER for a future real-customer environment.
- FIXED_OVERRIDE cannot silently fall back to a customer’s stored address.
- Missing or malformed override configuration fails safely.
- Both email delivery and API maskedDestination use the effective routed address.
- The frontend still cannot submit an email destination.
- Automated Maven tests are now forced to keep real email disabled, even if the surrounding Eclipse environment enables Gmail.
- Your Gmail address and App Password were not hardcoded anywhere.
